# Relay Protocol Indexer App

A community-built interface for monitoring Relay Protocol transaction indexing.

## Project status

This project is discontinued. Relay's API is changing, and public read-only access is no longer available in a sustainable way. Keeping live indexing would require hosting a server to provide an API key, so development has ended.

See Relay's [Requests v3 migration guide](https://docs.relay.link/references/api/api_guides/migrating-to-requests-v3) for details about the API changes.

The [website](https://warengonzaga.github.io/relay-protocol-indexer-app/) remains available as a static demo. It does not submit or look up transactions.
